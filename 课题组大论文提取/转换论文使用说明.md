# DeepSeek-OCR 论文转换使用说明

## 目录结构

- `papers/` - 存放需要转换的 PDF 论文文件
- `outputs/` - 存放转换后的 Markdown 文件

## 转换步骤

### 1. 准备文件

将需要转换的 PDF 论文文件放入 `课题组大论文提取/papers/` 目录。

### 2. 修改配置文件（使用自动化脚本）

在 `课题组大论文提取/` 目录中执行：

```bash
cd 课题组大论文提取
python edit_config.py 你的论文文件名.pdf
```

**示例：**
```bash
python edit_config.py 刘浩杨-毕业论文.pdf
```

脚本会自动更新 `DeepSeek-OCR-master/DeepSeek-OCR-vllm/config.py` 中的路径：
```python
INPUT_PATH = '课题组大论文提取/papers/刘浩杨-毕业论文.pdf'
OUTPUT_PATH = '课题组大论文提取/outputs/刘浩杨-毕业论文'
```

### 3. 执行转换命令

在项目根目录执行：

```bash
cd /home/xxy/projects/DeepSeek-OCR
CUDA_VISIBLE_DEVICES=2 .venv-vllm/bin/python DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py
```

**说明：**
- `CUDA_VISIBLE_DEVICES=2` 指定使用 GPU 2（可根据实际情况修改为 2 或 3）
- 转换过程可能需要较长时间，取决于 PDF 页数

### 4. 获取结果

转换完成后，在 `课题组大论文提取/outputs/你的论文文件名/` 目录下会生成以下文件：

- `你的论文文件名.mmd` - 转换后的 Markdown 文件（主要输出）
- `你的论文文件名_det.mmd` - 包含检测信息的 Markdown 文件
- `你的论文文件名_layouts.pdf` - 包含布局标注的 PDF 文件
- `images/` - 提取的图片文件（如果有）

### 5. 分章节处理（可选）

如果需要将论文按章节分割为单独文件，在 `课题组大论文提取/` 目录中执行：

```bash
cd 课题组大论文提取
python split_chapters.py outputs/你的论文文件名/你的论文文件名.mmd outputs/你的论文文件名/chapters
```

**说明：**
- 脚本会自动识别章节标题（如 `## 摘要`、`## 1 绪论`、`## 2 深水网箱...` 等）
- 只保留重要章节（摘要、绪论、正文章节、总结与展望）
- 自动跳过不需要的章节（致谢、目录、参考文献、作者简历等）
- 输出文件命名格式：`0-中英文摘要.md`、`1-绪论.md`、`2-深水网箱鱼群统计.md` 等

**输出示例：**
```
课题组大论文提取/outputs/你的论文文件名/chapters/
├── 0-中英文摘要.md
├── 1-绪论.md
├── 2-深水网箱鱼群统计.md
├── 3-开放海域鱼类统计.md
└── 4-总结与展望.md
```

### 6. 章节文档清理（可选）

分章节 Markdown 文件中可能包含模型生成的页面分隔标记或 HTML 表格，在 `课题组大论文提取/` 目录中执行：

```bash
cd 课题组大论文提取
python postprocess_chapter_md.py outputs/你的论文文件名/chapters
```

**作用：**
- 自动移除 `<--- Page Split --->` 分隔标记；
- 将 `<table>...</table>` 转换为标准 Markdown 表格（保留 `<br>` 等换行）；
- 将 `![](images/xxx.jpg)` 统一调整为 `![](../images/xxx.jpg)`，确保章节目录可正确引用图片。

## 完整命令示例

假设要转换 `papers/论文A.pdf`：

```bash
# 1. 修改 config.py 中的路径
cd /home/xxy/projects/DeepSeek-OCR/课题组大论文提取
python edit_config.py 论文A.pdf

# 2. 执行转换
cd /home/xxy/projects/DeepSeek-OCR
CUDA_VISIBLE_DEVICES=2 .venv-vllm/bin/python DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py

# 3. 转换完成后，结果在 课题组大论文提取/outputs/论文A/论文A.mmd

# 4. （可选）分章节处理
cd /home/xxy/projects/DeepSeek-OCR/课题组大论文提取
python split_chapters.py outputs/论文A/论文A.mmd outputs/论文A/chapters

# 5. （可选）章节清理
python postprocess_chapter_md.py outputs/论文A/chapters
# 分章节结果在 课题组大论文提取/outputs/论文A/chapters/ 目录下
```

## 注意事项

1. **GPU 选择**：根据 `nvitop` 查看可用 GPU，通常使用 GPU 2 或 3
2. **内存限制**：如果 GPU 内存不足，可以在 `config.py` 中降低 `MAX_CONCURRENCY` 和 `MAX_CROPS`
3. **模型路径**：当前使用本地模型路径，无需下载
4. **后台运行**：如需后台运行，可使用 `nohup`：
   ```bash
   CUDA_VISIBLE_DEVICES=2 nohup python run_dpsk_ocr_pdf.py > ../../outputs/转换日志.log 2>&1 &
   ```

## 配置参数说明

在 `config.py` 中可以调整的参数：

- `BASE_SIZE` / `IMAGE_SIZE` / `CROP_MODE` - 图像处理模式（Gundam 模式：1024/640/True）
- `MAX_CONCURRENCY` - 最大并发数（默认 100，GPU 内存不足时可降低）
- `MAX_CROPS` - 最大裁剪数（默认 6，GPU 内存不足时可降低到 4）
- `PROMPT` - 转换提示词（默认：`<image>\n<|grounding|>Convert the document to markdown.`）
