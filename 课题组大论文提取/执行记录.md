# 刘浩洋
## 执行命令序列
```bash
# 在 课题组大论文提取/ 目录执行
cd /home/xxy/projects/DeepSeek-OCR/课题组大论文提取

# 修改 config.py 中的路径
python edit_config.py 刘浩杨-毕业论文.pdf

# 大模型提取整个论文pdf（回到项目根目录执行）
cd /home/xxy/projects/DeepSeek-OCR
CUDA_VISIBLE_DEVICES=2 .venv-vllm/bin/python DeepSeek-OCR-master/DeepSeek-OCR-vllm/run_dpsk_ocr_pdf.py

# 提取章节（回到工作目录）
cd /home/xxy/projects/DeepSeek-OCR/课题组大论文提取
python split_chapters.py outputs/刘浩杨-毕业论文/刘浩杨-毕业论文.mmd outputs/刘浩杨-毕业论文/chapters

# 清理章节文档（去除 Page Split、转换表格）
python postprocess_chapter_md.py outputs/刘浩杨-毕业论文/chapters
```
